
# ♿ Acessibilidade na Escola

## Sobre o projeto

O projeto Acessibilidade na Escola foi desenvolvido utilizando HTML5 e CSS3.

O objetivo é apresentar informações sobre como tornar o ambiente escolar mais acessível e inclusivo.

A página utiliza cards informativos para explicar práticas importantes de acessibilidade.

O site possui uma organização simples, com textos objetivos e cores suaves.

## Tecnologias

- HTML5
- CSS3
- GitHub
- GitHub Pages

## Práticas de acessibilidade

- Textos simples e fáceis de compreender.
- Boa organização das informações.
- Contraste adequado entre texto e fundo.
- Fonte legível.
- Botões com nomes claros.
- Poucas cores e elementos visuais.
- Espaçamento entre os cards.
- Estrutura HTML semântica.
- Layout responsivo para celulares.
- Foco visível na navegação pelo teclado.

## Reflexão

**Qual foi a principal preocupação que você teve ao criar uma página acessível?**

Minha principal preocupação foi criar uma página fácil de compreender e navegar.

Procurei utilizar textos curtos e objetivos para facilitar a leitura.

Também escolhi cores suaves e organizei as informações em cards separados.

Outra preocupação foi garantir que o site funcionasse em computadores e celulares.

Acredito que uma página acessível deve ser simples e organizada.

Assim, mais pessoas podem encontrar e compreender as informações.

A acessibilidade ajuda a promover inclusão, autonomia e igualdade.
